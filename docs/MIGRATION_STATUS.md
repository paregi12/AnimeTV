# KMP migration status

## Scope

- First targets: Android phones and Android TV family devices.
- Desktop targets are deferred.
- Recreate the current UI and keep its behavior and feature set.
- Keep the existing AnimeTV directory unchanged; this project is developed separately in the sibling `kmp` directory.

## Source inventory

Only Gotaku and ReAnime are included as selectable catalog and playback sources, matching the providers that were enabled and working in the original app.

| Existing area | Current implementation | KMP destination |
| --- | --- | --- |
| Main UI, navigation, search, home lists, settings, details and player OSD | HTML/CSS and the 24k-line `m.js` | Shared Compose UI and common Kotlin state |
| Android host and TV input/lifecycle behavior | `MainActivity.java`, `AnimeView.java` | Kotlin Android app entry point and Android platform services |
| HTTP interception and source proxying | `AnimeApi.java`, `GotakuProxy.java`, `ReAnimeProxy.java` | Common repository/source logic with Android networking adapters where needed |
| Streaming and media controls | `AnimeDataSource.java` plus WebView/Media3 integration | Android Media3 playback implementation with shared playback state |
| Local channel/provider integrations | `AnimeProvider.java`, channel service classes | Android-only integration layer |
| Encryption and translation helpers | Java utility classes | Common Kotlin utilities where APIs allow; Android adapters otherwise |
