# Changelogs
- **1.0.0**
  - Migrated AnimeTV to the Kotlin Multiplatform (KMP) and Compose Multiplatform framework
  - Rebuilt the TV (DPAD) and mobile touch UI natively in Jetpack Compose Multiplatform
  - Migrated Gotaku and Reanime sources with local stream proxy and AES/XOR decryption
  - Added native AniList and MyAnimeList tracking, lists, review scores, and trailer playback
  - Built native Media3/ExoPlayer video player with customizable styled subtitles, subtitle translation, and intro/outro skip
  - Added in-app updater, low-end device memory and rendering optimizations, and signed release builds
